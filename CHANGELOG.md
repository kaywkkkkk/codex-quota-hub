# Changelog

## 1.0 — Initial release

Codex Quota Hub 1.0 is the project's first public release.

Multi-account quota overview and reset alerts for Codex.

Included in this release:

- Windows x64 desktop app and command-line tool.
- Usage queries for the current Codex account and Workspace, with local SQLite snapshots.
- Remaining quota, reset times, and offline countdowns.
- Detailed, Grid, and Compact views, with dark and light themes.
- Traditional Chinese, English, and Simplified Chinese interfaces.
- Account aliases and historical snapshots.
- Daily token usage for the last 7 days and daily totals across accounts with data.
- Manual reset credit counts, sources, statuses, and expiration details.
- Windows system tray alerts and optional Telegram due notifications.
- Configurable refresh intervals, pause monitoring, and retry backoff for failed queries.
- Complete source code, tests, build configuration, and release packaging script.
- English, Traditional Chinese, and Simplified Chinese README files.
